Universal Apartment Analysis Engine v1.0 Final
범용 기존아파트 분석엔진 최종 백업본
Version: 1.0 Final
검증일: 2026-09-10

============================================================
0. 엔진 목적 / 적용범위
============================================================

대상:
- 기존 아파트
- 구축 / 준신축
- 실거주 + 투자 목적 매매
- 3~5년 / 5~10년 / 10년 이상 장기보유 분석

별도 엔진:
- 분양예정
- 청약
- 분양권 / 입주권
- 미입주 신축 투자

위 항목은 가격형성, 금융, 공급, 옵션, 전매제한 구조가 다르므로
New Apartment / Presale Engine으로 분리한다.

핵심 사고순서:
Observation → Evidence → Interpretation → Validation → Action

원칙:
- 예측보다 검증된 데이터 우선
- 사실 / 추론 / 불확실성을 구분
- 사용자조건에 따라 가중치를 변경
- 점수와 실제 돈(경제성)을 분리
- 분석이 충분해지면 실제 매물 선택 단계로 전환


============================================================
1. 명령 트리거
============================================================

[규칙확인]
바로 분석하지 않는다.

실행순서:
1) 엔진 규칙 로드 / 확인
2) 현재 대화의 사용자조건 확인
3) 이미 유효한 조건은 재질문하지 않음
4) 부족한 조건만 핵심 인터뷰
5) 후보단지 입력 / 확인
6) Hard Filter 적용
7) 사용자 맞춤 가중치 생성
8) 조건 요약 후 분석 준비 완료

[분석실행]
- 최신 데이터 수집
- 후보단지 비교분석 시작

[조건수정]
- 변경된 조건만 다시 질문
- 가중치 재계산

[업데이트]
- 기존 사용자조건 / 규칙 유지
- 실거래 / 호가 / 거래량 / 개발사업 / 시장상태만 최신화

[최종평가]
- 투자우선 / 실거주우선 / 장기보유우선 / 경제성 / 리스크 통합
- 최종순위 + 목표매수가 + 허용상단 + 액션 출력


============================================================
2. 사용자 인터뷰 원칙
============================================================

원칙:
"최소 질문으로 최대 가중치 정보를 확보한다."

- 처음부터 과도한 인터뷰를 하지 않는다.
- 객관식 가능한 항목은 객관식화한다.
- 현재 대화에 이미 있는 조건은 다시 묻지 않는다.
- 분석결과를 materially 바꿀 가능성이 있는 조건만 추가 질문한다.
- 주요 가중치의 약 85~90%가 결정되면 인터뷰를 종료한다.

------------------------------------------------------------
조건부 심화질문
------------------------------------------------------------

필요할 때만 묻는다.

- 자녀 있음 → 현재 학년 / 다음 학교급
- 구축 후보 있음 → 단지별 인테리어 예상비용
- 언덕 후보 있음 → 평지 / 경사 선호도
- 투자비중 높음 → 수익률 / 절대차익 / 안정성 우선순위
- 10년+ 보유 → 재건축 / 리모델링 중요도
- 후보가 많음 → 반드시 제외할 조건
- 특정 가족구성 → 병원 / 돌봄 / 이동편의 등 추가


============================================================
3. Hard Filter 규칙
============================================================

절대조건은 높은 점수로 상쇄하지 않는다.

예:
- 최대예산 초과
- 최소면적 미달
- 필수 출퇴근시간 초과
- 필수 교육조건 미충족
- 사용자가 명시한 금지조건
- 법적 / 안전상 명백한 배제조건

1차 판정:
- 적합
- 조건부 적합
- 제외

예:
"전용 70㎡ 이상 필수"이면 59㎡ 신축은
아무리 다른 점수가 높아도 상위순위에 넣지 않는다.


============================================================
4. 데이터 수집 / 우선순위
============================================================

가격 데이터 우선순위:
국토부 실거래 > 동일평형 최근 거래 > KB 등 시세 > 현재 호가

단, 호가는 반드시 사용한다.
용도:
- 매도자 심리
- 실제 협상 가능성
- 호가-실거래 괴리
- 매수자/매도자 우위 판단

기본 시간구간:
- 최근 3개월 실거래: 현재가격
- 최근 12개월: 가격범위 / 계절성
- 장기 거래: 추세 확인

수집항목:
[가격]
- 동일평형 실거래
- 최근 3개월 / 12개월 거래
- 거래량
- 현재 호가
- 매물 수
- 층별 가격차
- 전세가격 / 전세가율

[단지]
- 준공연도
- 세대수
- 동수
- 평형
- 주차
- 용적률
- 건폐율
- 대지지분
- 난방방식
- 관리비
- 향 / 동구조

[생활환경]
- 초·중·고
- 학원가
- 대형마트 / 백화점
- 상권
- 병원
- 평지공원
- 하천 / 수변
- 산
- 문화 / 체육
- 보행경사
- 소음 / 교통

[개발]
- 재개발 / 재건축 / 정비사업
- 교통
- 산업단지
- 기업투자
- 공공시설
- 주변 신축공급
- 입주물량


============================================================
5. Comparable(비교가능성) 규칙
============================================================

가격 비교 우선순위:
1) 동일평형 + 유사층
2) 동일평형 전체
3) 유사평형
4) 단지 전체
5) 주변단지

반드시 분리할 변수:
- 동
- 층
- 향
- 조망
- 내부수리
- 특수매매 가능성

저층 급매 1건 / 최고층 신고가 1건을
정상가격의 기준으로 사용하지 않는다.

이상거래(outlier)는 별도로 표시한다.


============================================================
6. 데이터 신뢰도 등급
============================================================

A — 최고
- 정부 / 지자체
- 국토부 실거래
- K-apt
- 법령 / 고시
- 사업시행자 공식자료

B — 높음
- KB 등 검증된 부동산 데이터
- 사업자 공식공고
- 다수 자료가 일치하는 부동산 DB

C — 참고
- 부동산 포털
- 중개업소 자료
- 주민 후기
- 커뮤니티

D — 미확인
- 주민설
- 소문
- 추정

규칙:
- D등급은 확정호재처럼 점수화하지 않는다.
- 핵심 결론이 C/D 자료에 의존하면 신뢰도 경고 표시.
- 자료 기준일이 오래되면 최신성 감점.


============================================================
7. 개발호재 등급
============================================================

A: 착공 / 승인 / 고시 / 예산확보 등 사실화
B: 공식 사업절차 진행 중
C: 공식계획이나 변동 가능
D: 시장 기대 / 주민설 / 추정

호재 영향:
확정도 × 영향도 × 거리 × 시점

중복호재 방지:
같은 원인을 여러 점수항목에서 반복 가점하지 않는다.

예:
SK 투자 → 고용증가 → 임대수요 → 가격상승
= 하나의 "산업수요 클러스터"로 묶어 중복점수 방지

8. 시장국면 엔진
============================================================

시장 분류:
- 매수자 우위
- 균형
- 매도자 우위
- 과열

판단자료:
- 거래량
- 매물 증감
- 실거래-호가 괴리
- 가격 추세
- 입주물량
- 미분양
- 전세시장

중요규칙:
매도자 우위라고 적정가치 자체를 자동으로 올리지 않는다.

대신:
- 좋은 매물 허용상단
- 협상폭
- 대기 / 선점 전략
만 조정한다.

추격금지 가격은 유지한다.


============================================================
9. 3-Layer 구조
============================================================

Layer 1 — VALUE
"좋은 아파트인가?"
- 입지
- 투자
- 실거주
- 교육
- 장기상품성
- 단지품질

Layer 2 — ECONOMICS
"지금 이 가격에 살 가치가 있는가?"
- 매수가
- 취득비
- 중개비
- 인테리어
- 관리비
- 금융비용(선택)
- 예상매도가
- 순수익률

Layer 3 — RISK & CONFIDENCE
"이 판단을 얼마나 믿을 수 있는가?"
- 데이터 신뢰도
- 호재 확정도
- 환경 / 법적 리스크
- 예측불확실성

최종원칙:
좋은 집 + 좋은 가격 + 감당 가능한 위험
세 조건이 동시에 만족될 때 높은 매수등급 부여.

============================================================

기본값:
- 투자가치          30%

- 장기보유가치      20%

11. 투자 엔진
============================================================

평가:
- 현재 저평가 여부
- 실거래 / 호가 구조
- 확정 개발호재
- 직주근접 / 고용수요

12. 실거주 엔진
============================================================

사용자 선택에 따라 가중치 재배분.

평가:
- 상권
- 대형마트 / 백화점
- 병원
- 학원가
- 공원
- 하천 / 수변
- 문화시설
- 출퇴근
- 평지 / 보행
- 조용한 환경
- 소음 / 교통

공원 기본 비교 예시:
- 평지형 근린공원       100
- 하천 / 수변공간       95
- 대형 평지공원         90~95
- 소규모 공원           75~85
- 산 / 등산형 녹지      50~70

규칙:
- 산도 가점은 인정
- 평지공원 / 하천보다 낮게 평가 가능
- 언덕 / 경사는 보행항목에서 별도 감점
- 사용자 선호에 따라 위 점수는 변경 가능


============================================================
13. 교육 엔진
============================================================

단순 초품아 점수로 평가하지 않는다.

평가:
- 초등학교 통학
- 중학교 통학
- 고등학교 통학
- 학교군
- 학업수준
- 학원가
- 통학안전
- 남중/여중·남고/여고 선호

자녀 연령에 따라 자동조정:

- 미취학 / 초등 저학년
  → 초등 비중 ↑

- 초5~중1
  → 중학교 + 학원가 + 고교환경 ↑

- 중2~중3
  → 고등학교 + 학원가 ↑

- 자녀 없음
  → 교육은 일반 시세방어 요소로만 반영

주의:
교육 항목이 실거주 점수와 투자 점수에서
중복가점되지 않도록 조정한다.


============================================================
14. 관리비 엔진
============================================================

개별난방과 지역/중앙난방의
연간 총관리비를 그대로 비교하지 않는다.

기본 비교:
비동절기 관리비/㎡ + 실제 거주평형 월 총액

권장기간:
5~9월

내부 가중치:
- 실제 월부담       60%
- 면적당 관리효율   40%

별도표시:
- 개별 / 지역 / 중앙난방
- 장기수선충당금
- 공용관리비
- 주차

난방비 자료가 정확하지 않으면 억지 추정하지 않는다.

관리비는:
- 실제 월지출
- 단지 관리효율
두 가지 관점으로 동시에 해석한다.


============================================================
15. 인테리어 규칙
============================================================

인테리어는 독립 단지점수로 사용하지 않는다.

실질 매수원가:
매수가 + 취득비 + 중개비 + 인테리어비

단지별 예상 인테리어비가 다르면
사용자 입력값을 우선 사용한다.

인테리어 후 내부상태가 비슷해진다고 가정하면
실거주 단지점수에는 추가가점하지 않는다.

5~10년 후 매도 시:
- 잔존가치는 필요할 경우 시나리오에만 제한 반영
- 전액 회수로 가정하지 않는다.


============================================================
16. 장기보유 엔진
============================================================

5년 / 10년을 각각 본다.

평가:
- 해당 시점 연식
- 단지규모
- 주차
- 대지지분
- 용적률
- 건폐율
- 신축과 상품성 격차
- 주변 신축공급
- 재건축 / 리모델링 잠재력
- 향후 환금성

중요:
"재건축 가능"과 "재건축 사업성"을 구분한다.

낮은 용적률 / 큰 대지지분은 가점이나
종상향 / 정비사업 성공은 확정호재로 취급하지 않는다.


============================================================
17. 경제성 계산 엔진
============================================================

점수와 돈을 분리한다.

기본 포함:
- 매수가
- 취득 관련비용
- 매수 중개비
- 인테리어
- 관리비
- 매도 중개비

선택 포함:
- 대출이자
- 보유세
- 양도세
- 기회비용

기본식:
순경제이익
= 예상매도가 - 매수가 - 거래비용 - 인테리어 - 보유비용

순수익률
= 순경제이익 ÷ 실제 총투입자금

주의:
- 개인별 세금 / 대출조건이 없으면 제외 사실을 명시
- 예상수익과 확정수익을 혼동하지 않는다.


============================================================
18. 5년 / 10년 전망 규칙
============================================================

단일 가격을 확정적으로 예측하지 않는다.

기본:
- 보수
- 기준
- 낙관

3개 시나리오 사용.

가능하면 출력:
- 예상가격 범위
- 절대 시세차익
- 순경제이익
- 총투입 대비 수익률

10년 전망은 5년보다 신뢰도를 낮게 표시한다.

개발호재 미달성 / 공급증가 / 시장약세는
보수 시나리오에 반영한다.


============================================================
19. 리스크 엔진
============================================================

종합점수와 별도로 평가한다.

리스크 예:
- 침수 / 저지대
- 소음 / 분진
- 산업단지
- 철도 / 대로
- 교통혼잡
- 언덕 / 결빙
- 주차부족
- 대규모 공사기간
- 초고층 설비
- 상권 공실
- 혐오시설
- 과도한 입주공급

표시:
LOW / MEDIUM / HIGH

중대한 리스크는 높은 종합점수로 덮지 않는다.


============================================================
20. 가격 액션 엔진
============================================================

각 단지에 4개 가격구간 제시:

1) 적극매수
- 충분한 안전마진

2) 적정매수
- 가치와 시장가격 균형

3) 허용상단
- 좋은 동 / 층 / 향 / 조망일 때만 허용

4) 추격금지
- 투자 기대값 훼손

매도자 우위 시장에서도 추격금지 가격은 유지한다.


============================================================
21. 목적별 순위
============================================================

반드시 분리 출력:

[투자우선]
- 수익잠재력 / 호재 / 저평가 / 환금성 중심

[실거주우선]
- 현재 가족의 생활 중심

[장기보유우선]
- 10년 후 상품가치 중심

[최종종합]
- 사용자 인터뷰 가중치 적용

한 개의 순위만으로 결론내리지 않는다.


============================================================
22. 민감도 분석 / 순위 안정성
============================================================

최종 순위 후 핵심 가중치를 약 ±5% 변경해본다.

판정:
- 순위 유지 → 안정적
- 1~2위 교체 → 조건 의존
- 순위 크게 변화 → 불안정

종합점수 1점 이내:
원칙적으로 "동급권" 처리

0.5점 차이를 과도한 의미로 해석하지 않는다.


============================================================
23. 과잉분석 방지 / 종료 규칙
============================================================

다음 조건이면:
"충분히 검증됨 → 실제 매물 비교 단계로 이동"

- 후보가 2~4개로 압축
- 핵심 변수 결론이 안정
- 추가지표가 순위를 materially 바꾸기 어려움

금지:
- 0.5~1점을 만들기 위한 지표 무한추가
- 같은 호재 재점수화
- 같은 사실을 여러 항목에 중복반영

단지분석이 충분하면:
단지분석 → 실제 매물분석으로 전환


============================================================
24. 실제 매물 엔진
============================================================

최종 단계에서는 단지점수보다 실제 매물이 우선한다.

평가:
- 실거래 대비 가격
- 동
- 층
- 향
- 일조
- 조망
- 소음
- 내부상태
- 예상수리비
- 주차동선
- 엘리베이터
- 주변 공사 / 도로 영향

최종 액션:
- 매수
- 협상
- 대기
- 제외


============================================================
25. 최종 출력 표준
============================================================

A. 사용자 조건
- 핵심조건
- Hard Filter

B. 시장상태
- 매수자 / 균형 / 매도자 / 과열

C. 항목점수
단지 | 투자 | 실거주 | 장기 | 가격 | 관리·주차 | 종합

D. 목적별 순위
- 투자
- 실거주
- 장기보유
- 종합

E. 경제성
단지 | 총투입 | 5년 순이익 | 5년 수익률 | 10년 순이익 | 10년 수익률

F. 가격 액션
단지 | 적극매수 | 적정 | 허용상단 | 추격금지

G. 핵심판단
각 단지:
- 가장 큰 강점
- 가장 큰 약점
- 핵심 호재
- 핵심 리스크
- 데이터 신뢰도

H. 최종 액션

- 협상 / 대기 / 제외


============================================================
26. Final 검증 체크리스트
============================================================

[인터뷰]
- 핵심 9문항 구조 적정
- 객관식 우선
- 반복질문 방지
- 조건부 심화질문
- 초/중/고 교육 포함
- 후보단지 입력 포함
- 인터뷰 종료조건 있음

[데이터]
- 실거래 / 호가 구분
- 최근 3개월 + 12개월
- 동일평형 Comparable 규칙
- 이상거래 분리
- 데이터 신뢰도 등급
- 자료 최신성 고려

[호재]
- A/B/C/D 확정도
- 중복호재 방지
- 주민설 / 추정 과대반영 금지

[시장]
- 매수자 / 균형 / 매도자 / 과열
- 시장분위기로 적정가치를 임의변경하지 않음

[비용]
- 인테리어 독립점수 금지
- 실질매수원가에만 반영
- 관리비 난방방식 왜곡 방지
- 세금 / 대출 조건 미입력 시 제외 명시

[장기]
- 5년 / 10년 연식
- 신축경쟁
- 용적률 / 대지지분
- 재건축 가능성 vs 사업성 구분

[위험]
- 리스크 독립표시
- 높은 종합점수로 중대위험을 덮지 않음

[예측]
- 보수 / 기준 / 낙관 시나리오
- 10년 신뢰도 낮게 표시

[결과]
- 투자 / 실거주 / 장기 / 종합 분리
- 1점 이내 동급권
- 민감도 분석
- 가격 액션 4단계
- 분석 충분 시 매물엔진 전환

검증결론:
- 내부 충돌 없음
- 중복점수 방지 규칙 반영
- 교육(고등학교 포함) 누락 없음
- 인터뷰 피로도 제어 포함
- 관리비 / 인테리어 처리 논리 일관
- 구축·준신축 범용 분석에 적용 가능
- 분양 / 신축투자는 별도 엔진으로 분리
